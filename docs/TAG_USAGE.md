# 标签功能使用指南

## 什么是标签？

标签用于分类和组织文章，帮助读者快速找到相关内容。

## 如何使用标签

### 创建文章时添加标签

1. 填写文章标题和内容
2. 在"文章标签"输入框中输入标签名称
3. 按回车键或点击"添加"按钮
4. 重复添加多个标签
5. 点击标签上的 × 按钮可删除

**标签命名规则：**
- 长度：1-50个字符
- 支持：中文、英文、数字、空格、下划线（_）、连字符（-）

**示例标签：**
```
Java
Spring Boot
后端开发
教程
```

### 编辑文章时修改标签

进入文章编辑页面，可以添加、删除或修改标签。

### 查看文章标签

- **文章列表**：每篇文章显示前3个标签
- **文章详情**：显示所有标签（带颜色和图标）
- **热门标签**：主页右侧显示，点击可查看该标签的所有文章

## 标签特性

### 自动创建
首次使用的标签会自动创建，系统会分配随机颜色。

### 标签颜色
每个标签有独特的颜色用于视觉区分，新标签会自动分配颜色。

## 最佳实践

### 标签数量
建议每篇文章添加 3-5 个标签。

### 标签选择

**技术栈标签**
```
Java, Python, JavaScript, Spring, React, Vue
```

**主题标签**
```
后端开发, 前端开发, 数据库, 教程, 实战
```

### 标签层次
使用不同层次的标签，如：
- 技术：Spring Boot, Java
- 类型：实战, 教程
- 主题：后端开发

## 常见问题

**Q: 可以使用中文标签吗？**
A: 可以。标签支持中文、英文和混合使用。

**Q: 标签会影响文章显示吗？**
A: 不会。标签只是辅助信息。

**Q: 删除标签会删除文章吗？**
A: 不会。删除标签只是移除关联关系。

**Q: 可以修改已添加的标签吗？**
A: 可以。进入文章编辑页面即可修改。

**Q: 标签有大小写区分吗？**
A: 有。建议统一使用规范命名。

## 使用技巧

1. **先思考再添加**：考虑文章核心主题和读者搜索习惯
2. **参考已有标签**：查看相似文章使用的标签
3. **定期检查更新**：编辑文章时检查标签是否还符合内容
