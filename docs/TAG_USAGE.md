# 标签功能使用指南

## 什么是标签？

标签是用于分类和组织文章的关键词。通过给文章添加标签，可以：
- 让读者快速了解文章主题
- 方便文章的分类管理
- 帮助读者找到相关内容

## 如何使用标签

### 1. 创建文章时添加标签

在创建新文章时：

1. 填写文章标题和内容
2. 找到"文章标签"部分
3. 在输入框中输入标签名称
4. 按回车键或点击"添加"按钮
5. 可以添加多个标签
6. 点击标签上的 × 按钮可以删除标签

**示例标签：**
```
Java
Spring Boot
后端开发
教程
```

**标签命名规则：**
- 长度：1-50个字符
- 支持：中文、英文、数字、空格、下划线（_）、连字符（-）
- 不支持：特殊符号（如 @#$%等）

### 2. 编辑文章时修改标签

编辑已有文章时：

1. 进入文章编辑页面
2. 系统会自动显示文章现有的标签
3. 可以删除不需要的标签
4. 可以添加新的标签
5. 保存文章后标签修改生效

### 3. 查看文章标签

**在文章列表中：**
- 每篇文章最多显示3个标签
- 如果标签超过3个，会显示 "+N" 提示剩余数量

**在文章详情页：**
- 文章标题下方会显示所有标签
- 标签以彩色徽章形式展示

## 标签特性

### 自动创建

当你添加一个不存在的标签时，系统会自动创建这个标签。你不需要预先创建标签，可以直接在写文章时添加。

**例如：**
- 你在文章中添加 "Vue.js" 标签
- 如果这是第一次使用 "Vue.js"，系统会自动创建
- 下次其他人使用时，就会关联到同一个标签

### 标签一致性

为了保证标签的一致性，建议：
- 使用常见的、标准的标签名称
- 避免创建过于相似的标签（如 "Java" 和 "java"）
- 标签名称尽量简洁明了

**推荐做法：**
- ✅ "JavaScript"（标准写法）
- ❌ "javascript"、"java script"（不统一）

- ✅ "前端开发"
- ❌ "前端"、"前端技术"、"前端开发技术"（过于分散）

## 最佳实践

### 1. 标签数量

建议每篇文章添加 3-5 个标签：
- 太少：不利于分类和发现
- 太多：显得杂乱，失去重点

### 2. 标签选择

选择标签时考虑：

**技术栈标签**
```
Java, Python, JavaScript, TypeScript, Go
Spring, Django, React, Vue, Express
```

**主题标签**
```
后端开发, 前端开发, 数据库, 算法
教程, 实战, 原理解析, 最佳实践
```

**难度标签**
```
入门, 进阶, 高级
```

### 3. 标签层次

建议使用不同层次的标签：

**示例文章：《Spring Boot 实战：构建 RESTful API》**
- 技术：Spring Boot, Java
- 类型：实战, 教程
- 主题：后端开发, RESTful

这样既有具体的技术标签，也有抽象的主题标签，方便不同需求的读者找到文章。

## 常见问题

### Q1: 可以使用中文标签吗？
A: 可以！标签支持中文、英文和混合使用。

### Q2: 标签会影响文章显示吗？
A: 不会。标签只是辅助信息，不影响文章的核心内容显示。

### Q3: 删除标签会删除文章吗？
A: 不会。删除标签只是移除文章和标签的关联关系，不会删除文章本身。

### Q4: 可以修改已添加的标签吗？
A: 可以。进入文章编辑页面，可以删除、添加或修改标签。

### Q5: 标签有大小写区分吗？
A: 有。"Java" 和 "java" 会被视为不同的标签。建议统一使用规范的命名。

### Q6: 一篇文章最多可以添加多少个标签？
A: 从技术上讲没有硬性限制，但建议不超过8个标签，3-5个是最佳实践。

## 使用技巧

### 技巧1: 先思考再添加
在添加标签前，先思考：
- 这篇文章的核心主题是什么？
- 读者会用什么关键词搜索这类内容？
- 哪些标签最能代表文章内容？

### 技巧2: 参考已有标签
如果不确定用什么标签，可以：
- 查看相似文章使用了哪些标签
- 使用常见的、大家都在用的标签
- 避免创造太多新标签

### 技巧3: 定期检查更新
在编辑文章时：
- 检查标签是否还符合文章内容
- 删除不相关的标签
- 添加新的相关标签

## 总结

标签是一个简单但强大的功能。合理使用标签可以：
- 📌 让你的文章更容易被发现
- 🗂️ 帮助你更好地组织内容
- 🔍 方便读者找到相关主题

记住这些要点：
1. 每篇文章添加 3-5 个标签
2. 使用标准、常见的标签名称
3. 标签应该准确反映文章内容
4. 保持标签的一致性
