# 博客系统前端项目

基于 Vue 3 + Tailwind CSS 构建的现代化多用户博客系统前端。

## ✨ 核心特性

### 用户端
- 🎨 **现代化UI设计** - 响应式布局,毛玻璃效果,流畅动画
- 🔐 **完整认证系统** - JWT认证,"记住我",Token自动刷新
- ✍️ **Markdown编辑器** - 实时预览,代码高亮
- 💬 **社交功能** - 评论系统,点赞功能,子评论/回复,**用户关注**,**私信功能**
- 📝 **我的文章状态** - 审核/拒绝状态标识，未发布文章隐藏互动入口
- 🏷️ **内容组织** - 标签系统,分类功能,文章搜索
- 👤 **用户系统** - 个人主页,资料编辑,头像上传,悬浮卡片,**关注/粉丝列表**
- 📊 **社区统计** - 用户总数,文章总数,在线用户,今日访问
- 🔥 **热门作者榜单** - "品"字形布局,热度算法排名,悬浮卡片关注
- 🔒 **隐私控制** - 关注信息可见性设置
- 💌 **私信系统** - 实时聊天,防骚扰机制,已读状态,未读提醒

### 管理后台
- 🛡️ **RBAC权限控制** - 基于角色的访问控制（USER/ADMIN）
- 📊 **数据可视化仪表盘** - 核心指标统计、30天趋势图表、热门文章TOP10、标签/分类热力图、文章状态分布、内容质量雷达图、最近动态、系统概览；所有图表支持点击放大分析
- 📝 **内容管理** - 文章、分类、标签、评论管理
- 🖼️ **媒体库** - 文件管理,网格视图
- 👥 **用户管理** - 用户列表,多条件搜索,角色管理,批量操作,启用/禁用
- 📋 **操作日志** - 管理员操作审计记录,多条件搜索,详情查看,扩展信息展示
- ⚙️ **系统设置** - 表单配置,开关控制

## 🛠️ 技术栈

- **框架**: Vue 3 (Composition API)
- **路由**: Vue Router 4
- **状态管理**: Vuex 4
- **HTTP客户端**: Axios + JWT认证拦截
- **样式**: Tailwind CSS 3
- **数据可视化**: Chart.js 4 + vue-chartjs 5
- **Markdown**: marked + highlight.js
- **构建**: Vue CLI 5

## 📦 代码目录组织规范

本项目采用**模块化目录结构**，将前台（portal）与后台（admin）分离，公共能力保持在全局目录：

- **`api/`**: 所有 API 接口封装，按功能模块划分文件
- **`components/`**: 全局公共组件，可在前台和后台复用
- **`layouts/`**: 布局组件，如 AdminLayout
- **`modules/`**: 功能模块目录，按 portal（用户端）和 admin（管理后台）分离
  - 每个模块包含 `components/`（专用组件）、`views/`（页面）、`router.js`（路由）
- **`router/`**: 主路由入口，合并各模块路由
- **`store/`**: Vuex 状态管理
- **`utils/`**: 工具函数（Axios 封装、头像处理等）

## 🚀 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器 (http://localhost:3000)
npm run serve

# 生产构建
npm run build
```

## 🔐 管理后台

管理后台需要 ADMIN 角色才能访问。

### 访问入口

1. 使用管理员账户登录（统一登录页面）
2. 登录后在右上角用户菜单中点击"管理后台"
3. 或直接访问 `/admin` 路由

### 功能模块

| 模块 | 功能 |
|------|------|
| 仪表盘 | 核心统计卡片（可点击详情）、30天趋势图表（用户/文章/评论/浏览量）、热门文章TOP10（按热度公式）、标签/分类热力图、文章状态分布（环形图）、内容质量雷达图（6维度）、最近动态、系统概览；所有图表点击放大分析 |
| 文章管理 | 文章列表、多条件筛选（状态/作者/标签/日期）、批量审核/拒绝/删除、状态管理 |
| 分类管理 | 分类列表（按文章数排序）、多条件筛选、创建/编辑（含颜色选择）、查看关联文章、按ID或标题搜索添加文章、移除文章、批量删除（含关联文章检查）、删除通知 |
| 标签管理 | 标签列表（按热度排序）、多条件筛选、创建/编辑（含图标选择器）、软删除/硬删除、通知表单、批量操作 |
| 评论管理 | 评论审核、删除、多条件筛选、批量操作、删除通知表单 |
| 媒体库 | 文件网格、上传 |
| 用户管理 | 用户列表、多条件搜索、角色管理、批量启用/禁用、批量设置管理员 |
| 操作日志 | 管理员操作审计记录、15种操作类型、多条件搜索筛选、详情卡片、扩展信息展示 |
| 系统设置 | 网站配置、评论设置 |

### 设置管理员

```sql
UPDATE users SET role = 'ADMIN' WHERE username = 'your_admin_username';
```
